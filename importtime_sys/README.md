# ขอราคาพาร์ทต่างประเทศ

หน้าสำหรับบันทึกราคาพาร์ทที่ขอจากผู้ขายต่างประเทศ แล้วใช้ข้อมูลนั้นเขียนใบขอซื้อ (PR)

เปิดได้ที่

```text
http://localhost/importtime_sys/
```

ถ้าวางทั้งคลังนี้ไว้ในเว็บรูท ให้เปิด `http://localhost/<โฟลเดอร์คลัง>/importtime_sys/`

## สิ่งที่บันทึกได้

- ใบขอราคา: ผู้ขอ แผนก เครื่องจักร เหตุผลที่ซื้อ ผู้ขาย ประเทศ สกุลเงิน Incoterm เงื่อนไขชำระเงิน เลขที่ใบเสนอราคา วันหมดอายุราคา ระยะเวลาส่งของ ค่าขนส่ง และอัตราแลกเปลี่ยน
- รายการพาร์ท: รหัส ชื่อ สเปก ยี่ห้อ หน่วย จำนวน ราคาต่อหน่วย
- สถานะใบขอราคา: ร่าง, ขอราคาแล้ว, ได้ราคาแล้ว, ยกเลิก
- เมื่อได้ราคาครบแล้ว กด **สร้างใบขอซื้อ** เพื่อคัดลอกรายการและเงื่อนไขไปเป็น PR
- ในใบขอซื้อ ปรับจำนวนได้ไม่เกินจำนวนที่เสนอราคา แล้วพิมพ์หรือออกเอกสาร

## ความต้องการของระบบ

- PHP 8.0 ขึ้นไป พร้อม `pdo_mysql`, `mbstring`, `bcmath`, `json`
- MySQL 5.7+ หรือ MariaDB 10.3+
- Apache 2.4 (แนะนำ) หรือเซิร์ฟเวอร์ในตัวของ PHP

## วิธีติดตั้ง

### 1. นำเข้า SQL

ใน phpMyAdmin เลือกแท็บ **Import** แล้วเลือกไฟล์ `importtime_sys/database.sql`

ไฟล์นี้สร้างฐาน `importtime_sys` พร้อมตารางผู้ใช้ ผู้ขาย ใบขอราคา และใบขอซื้อ การนำเข้าซ้ำจะลบข้อมูลเดิมในฐานนี้

ถ้าบัญชีฐานข้อมูลไม่มีสิทธิ์ `CREATE DATABASE` ให้สร้างฐาน `importtime_sys` ด้วยชุดอักขระ `utf8mb4_unicode_ci` เอง แล้วลบบรรทัด `CREATE DATABASE` กับ `USE` ก่อนนำเข้า

### 2. คัดลอกไฟล์ตั้งค่า

```bash
cp config.sample.php config.php
```

แก้ค่าใน `config.php`

- `db_host`, `db_port`, `db_name`, `db_user`, `db_pass` ให้ตรงกับ MySQL
- `company_name` ชื่อบริษัทที่จะพิมพ์บนใบขอซื้อ

ไม่ต้องนำ `config.php` เข้า git

### 3. เปิดเว็บ

ชี้ DocumentRoot ไปที่โฟลเดอร์ `importtime_sys` หรือวางโฟลเดอร์นี้ใน htdocs แล้วเปิด

```text
http://localhost/importtime_sys/
```

ทดลองด้วยเซิร์ฟเวอร์ในตัวของ PHP:

```bash
cd importtime_sys
php -S localhost:8080 -t public
```

แล้วเปิด `http://localhost:8080/`
